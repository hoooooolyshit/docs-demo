# 第一章	计算机系统的概述

## 1 计算机的发展

**计算机系统 = 硬件 + 软件**

> 计算机性能的好坏取决于“软”、“硬”件功能的总和

**软件：**

- 系统软件：用来管理整个计算机系统
- 应用软件：按任务需要编制成的各种程序

**硬件的发展：**

- 第一代：==电子管时代==
- 第二代：==晶体管时代==
- 第三代：==中小规模集成电路时代==
- 第四代：==大规模、超大规模集成电路时代==

**目前的发展趋势：**

- 更微型、多用途
- 更巨型、超高速



## 2 计算机的硬件

### 2.1 计算机硬件的基本组成

**计算机硬件基本的五大部件：**

- 输入设备：将信息转换成机器能识别的形式
- 输出设备：将结果转换成人们熟悉的形式
- 主存储器：存放数据和程序
- 运算器：算术运算、逻辑运算
- 控制器：指挥各部件使程序运行

**冯诺依曼计算机结构：**

- 首次提出”存储程序“概念
- ==以运算器为中心==

**现代计算机结构：**

- ==以存储器为中心==
- CPU = 运算器 + 控制器



### 2.2 认识各个硬件部件

**主存储器：**

- 存储体：概念：存储元、存储单元、存储字、存储字长、地址
- MAR：<u>地址寄存器</u>，用于指明要读/写哪个存储单元。其位数反映存储单元数量
- MDR：<u>数据寄存器</u>，用于暂存要读/写的数据。其位数 = 存储字长

**运算器：**

- ACC：<u>累加计数器</u>，存放操作数、运算的结果
- MQ：<u>乘商寄存器</u>，进行乘除法时用得到
- X：<u>通用寄存器</u>，存放操作数
- ALU：<u>算数逻辑单元</u>，用电路实现各种算数运算、逻辑运算

**控制器：**

- PC：<u>程序计数器</u>，存放下一条指令的地址
- IR：<u>指令寄存器</u>，存放当前执行的指令
- CU：<u>控制单元</u>，分析指令，给出控制信号

**工作过程：**

1. 指令、数据存入主存，PC 指向第一条指令
2. 从主存中取指令放入 IR、PC 自动加 1、CU 分析指令、CU 指挥其他部件执行指令



## 3 计算机系统的层次结构

**计算机的五层结构：**

- M4：高级语言机器（执行高级语言）
- M3：汇编语言机器（执行汇编语言）
- M2：操作系统机器（向上提供广义指令）

- M1：传统机器（执行机器语言指令）
- M0：微程序机器（执行微指令）

**三个级别的语言：**

- 高级语言、汇编语言、机器语言
- 编译程序——将高级语言一次全部翻译为汇编语言
- 汇编程序——将汇编语言翻译成机器语言
- 解释程序——高级语言翻译为机器语言（翻译一句执行一句）



## 4 计算机的性能指标

**存储器的容量：**

- MAR 的位数反映存储单元数量
- MDR 反映每个存储单元的大小

**CPU：**

时钟周期：CPU 中最小的时间单位，每个动作至少要 1 个时钟周期

主频（时钟频率）：主频 = 1 / 时钟周期，单位：HZ

CPI：执行一条指令所需的时钟周期数

CPU 执行时间：运行一个程序所花费的时间，CPU 执行时间 = (指令条数 * CPI) / 主频

IPS：每秒执行多少条指令 = 主频 / 平均 CPI

FLOPS：每秒执行多少次浮点运算

**其他：**

数据通路宽度、吞吐量、响应时间、基准程序

**常用数量单位：**

描述存储容量、文件大小时：K = 2^10^, M = 2^20^, G = 2^30^, T = 2^40^

描述频率、速度时：K = 10^3^, M = 10^6^, G = 10^9^, T = 10^12^
