# 8.2阅读材料1：企业资源规划

​		企业资源规划（ERP）软件试图将整个公司的所有部门和职能整合到一个单一的计算机系统中，以满足所有不同部门的特殊需求。
​		ERP系统可以成为客户订单所在地，从客户服务代表收到订单到装货码头装运商品和财务部门发送发票。通过将这些信息放在一个软件系统中，而不是分散在许多无法相互通信的不同系统中，公司可以更轻松地跟踪订单，同时协调多个不同地点之间的制造、库存和运输。
​		ERP帮助制造流程更加顺畅，并提高了公司内部订单履行流程的可视性。这可以减少用于制造产品的材料的库存，并且可以帮助用户计划向客户交付，减少仓库和装运码头的成品库存。
​		ERP接受客户订单，并提供一个软件路线图，用于自动化实现订单过程中的不同步骤。当客户服务代表将客户订单输入ERP系统时，他拥有完成订单所需的所有信息。例如，来自财务模块的客户信用评级和订单历史记录、来自仓库模块的公司库存水平以及来自物流模块的装运码头卡车运输计划。
​		这些不同部门的人员都可以看到相同的信息，并可以对其进行更新。当一个部门完成订单时，它会通过ERP系统自动发送到下一个部门。要了解订单在任何时候的位置，您只需登录ERP系统并跟踪即可。幸运的是，订单流程就像闪电一样在组织中移动，客户获得订单的速度比以前更快，错误更少。ERP可以将同样的魔力应用于其他主要业务流程，如员工福利或财务报告。
​		ERP对许多大公司来说是一个有吸引力的解决方案，因为它提供了许多潜在的用途。例如，同一系统可用于产品需求、订购必要的原材料、制定生产计划、跟踪库存、分配成本和项目关键财务措施。作为公司核心业务流程的规划骨干。除了指导许多流程外，该系统还使用来自整个公司的数据将这些不同的流程联系在一起。例如，典型的ERP系统管理的功能和活动与物料清单、订单录入、采购、人力资源和库存控制等不同，仅举60个可用模块中的几个模块。根据需要，ERP还能够与其他公司软件系统共享来自这些过程的数据。ERP系统的另一个重要好处是，它们允许公司用一个单一的、集成的系统取代复杂的计算机应用程序。
​		然而，尽管有这些潜在的好处，传统的ERP系统也有一些缺点。例如，早期的系统往往是大型、复杂和昂贵的。实施需要公司信息技术部门或外部专业人员投入大量时间。此外，由于ERP系统影响到公司的大多数主要部门，它们往往会在许多业务流程中产生变化。因此，实施ERP需要新的程序、员工培训。以及管理和技术支持。因此，许多公司发现ERP是一个缓慢而痛苦的过程。一旦实施阶段完成，一些企业已经开始量化他们从ERP中获得的好处。
​		最后，随着技术开始转向快速连接、基于Web的企业对企业关系和电子商务，一些公司担心其基于大型机的ERP系统速度太慢。然而，事实证明，许多公司发现他们的ERP系统提供了通过规范业务流程，促进公司间的信息共享，以及创建一个组织来改变未来的增长，为未来的发展奠定坚实的技术基础。ERP系统可能会让那些安装成本高昂且痛苦不堪的公司感觉不舒服。然而，它们构成了广泛的新的价值提升应用的有价值的基础。
